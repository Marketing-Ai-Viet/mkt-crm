# GraphQL Auto-Generation trong Twenty CRM Engine

## Tổng quan

Twenty CRM sử dụng một hệ thống tự động sinh GraphQL schema và resolvers dựa trên **Object Metadata**. Điều này cho phép tự động tạo CRUD operations cho tất cả entities trong workspace mà không cần viết code thủ công.

## Luồng xử lý chi tiết

### 1. Entry Point: GraphQLConfigService

**File**: `graphql-config/graphql-config.service.ts`

```typescript
@Injectable()
export class GraphQLConfigService implements GqlOptionsFactory<YogaDriverConfig<'express'>> {
  createGqlOptions(): YogaDriverConfig {
    return {
      autoSchemaFile: true,
      conditionalSchema: async (context) => {
        // Lấy auth context từ request
        const { user, workspace, apiKey, workspaceMemberId, userWorkspaceId } = context.req;
        
        // Tạo schema động dựa trên workspace
        return await this.createSchema(context, {
          user, workspace, apiKey, workspaceMemberId, userWorkspaceId
        });
      },
      // ... plugins, rate limiting, etc.
    };
  }

  async createSchema(context, data: AuthContext) {
    // Resolve WorkspaceSchemaFactory theo request context
    const workspaceFactory = await this.moduleRef.resolve(WorkspaceSchemaFactory, contextId);
    return await workspaceFactory.createGraphQLSchema(data);
  }
}
```

**Điểm quan trọng**:
- Schema được tạo động (`conditionalSchema`) cho mỗi request
- Mỗi workspace có schema riêng dựa trên metadata của workspace đó
- Sử dụng `YogaDriver` từ `@graphql-yoga/nestjs`

### 2. WorkspaceSchemaFactory - Orchestrator chính

**File**: `workspace-schema.factory.ts`

```typescript
@Injectable()
export class WorkspaceSchemaFactory {
  async createGraphQLSchema(authContext: AuthContext): Promise<GraphQLSchema> {
    // 1. Lấy metadata của workspace
    const { objectMetadataMaps, metadataVersion } = 
      await this.workspaceMetadataCacheService.getExistingOrRecomputeMetadataMaps({
        workspaceId: authContext.workspace.id,
      });

    // 2. Lọc objects được expose qua API
    const objectMetadataCollection = Object.values(objectMetadataMaps.byId)
      .filter((obj) => !shouldExcludeFromWorkspaceApi(obj, standardObjectMetadataDefinitions, featureFlags));

    // 3. Kiểm tra cache typeDefs
    let typeDefs = await this.workspaceCacheStorageService.getGraphQLTypeDefs(workspaceId, metadataVersion);

    // 4. Nếu chưa cache, generate mới
    if (!typeDefs) {
      const autoGeneratedSchema = await this.workspaceGraphQLSchemaFactory.create(
        objectMetadataCollection,
        workspaceResolverBuilderMethodNames,  // { queries: [...], mutations: [...] }
      );
      typeDefs = printSchema(autoGeneratedSchema);
      // Cache lại
      await this.workspaceCacheStorageService.setGraphQLTypeDefs(workspaceId, metadataVersion, typeDefs);
    }

    // 5. Generate resolvers (không cache vì có auth context)
    const autoGeneratedResolvers = await this.workspaceResolverFactory.create(
      authContext,
      objectMetadataMaps,
      workspaceResolverBuilderMethodNames,
    );

    // 6. Tạo executable schema
    return makeExecutableSchema({
      typeDefs: gql`${typeDefs}`,
      resolvers: {
        ...scalarsResolvers,
        ...autoGeneratedResolvers,
      },
    });
  }
}
```

export class WorkspaceGraphQLSchemaFactory {
  async create(
    objectMetadataCollection: ObjectMetadataEntity[],
    workspaceResolverBuilderMethods: WorkspaceResolverBuilderMethods,
  ): Promise<GraphQLSchema> {
    // 1. Generate type definitions và lưu vào storage
    await this.typeDefinitionsGenerator.generate(objectMetadataCollection, options);

    // 2. Tạo schema với Query và Mutation types
    return new GraphQLSchema({
      query: this.queryTypeFactory.create(
        objectMetadataCollection,
        [...workspaceResolverBuilderMethods.queries],  // ['findMany', 'findOne', 'findDuplicates']
      ),
      mutation: this.mutationTypeFactory.create(
        objectMetadataCollection,
        [...workspaceResolverBuilderMethods.mutations],  // ['createOne', 'createMany', ...]
      ),
      types: this.orphanedTypesFactory.create(),
    });
  }
}

### 4. TypeDefinitionsGenerator - Sinh các GraphQL Types

@Injectable()
export class TypeDefinitionsGenerator {
  async generate(objectMetadataCollection: ObjectMetadataEntity[]) {
    // 1. Generate composite types (Address, FullName, Currency, etc.)
    await this.generateCompositeTypeDefs(options);
    
    // 2. Generate metadata object types
    await this.generateMetadataTypeDefs(objectMetadataCollection, options);
    
    // 3. Generate relation connect input types
    this.generateRelationConnectInputTypeDefs(objectMetadataCollection);
  }

  private async generateMetadataTypeDefs(objectMetadataCollection) {
    // Enum types cho các field có options (SELECT, MULTI_SELECT)
    this.generateEnumTypeDefs(objectMetadataCollection);
    
    // Object types cho output (Person, Company, etc.)
    this.generateObjectTypeDefs(objectMetadataCollection);
    
    // Pagination types (Edge, Connection)
    this.generatePaginationTypeDefs(objectMetadataCollection);
    
    // Input types (Create, Update, Filter, OrderBy)
    await this.generateInputTypeDefs(objectMetadataCollection);
    
    // Extended types cho relations
    await this.generateExtendedObjectTypeDefs(objectMetadataCollection);
  }
}

### 6. RootTypeFactory - Tạo Query và Mutation Types

**File**: `workspace-schema-builder/factories/root-type.factory.ts`

```typescript
@Injectable()
export class RootTypeFactory {
  create(
    objectMetadataCollection: ObjectMetadataEntity[],
    workspaceResolverMethodNames: WorkspaceResolverBuilderMethodNames[],
    objectTypeName: ObjectTypeName,  // Query | Mutation
  ): GraphQLObjectType {
    return new GraphQLObjectType({
      name: objectTypeName.toString(),
      fields: this.generateFields(objectMetadataCollection, workspaceResolverMethodNames),
    });
  }

  private generateFields(objectMetadataCollection, methodNames) {
    const fieldConfigMap = {};

    for (const objectMetadata of objectMetadataCollection) {
      for (const methodName of methodNames) {
        // Kiểm tra có nên build resolver này không
        if (this.workspaceResolverBuilderService.shouldBuildResolver(objectMetadata, methodName)) {
          const name = getResolverName(objectMetadata, methodName);
          const args = getResolverArgs(methodName);
          const objectType = this.typeDefinitionsStorage.getObjectTypeByKey(...);
          
          fieldConfigMap[name] = {
            type: outputType,
            args: argsType,
            resolve: undefined,  // Sẽ được set bởi ResolverFactory
          };
        }
      }
    }
    return fieldConfigMap;
  }
}
```

## Resolver Builder - Tạo Resolver Functions

### 7. WorkspaceResolverFactory

**File**: `workspace-resolver-builder/workspace-resolver.factory.ts`

```typescript
@Injectable()
export class WorkspaceResolverFactory {
  // Map từ method name đến factory tương ứng
  private factories = new Map([
    ['createMany', this.createManyResolverFactory],
    ['createOne', this.createOneResolverFactory],
    ['deleteMany', this.deleteManyResolverFactory],
    ['deleteOne', this.deleteOneResolverFactory],
    ['destroyMany', this.destroyManyResolverFactory],
    ['destroyOne', this.destroyOneResolverFactory],
    ['findDuplicates', this.findDuplicatesResolverFactory],
    ['findMany', this.findManyResolverFactory],
    ['findOne', this.findOneResolverFactory],
    ['restoreMany', this.restoreManyResolverFactory],
    ['restoreOne', this.restoreOneResolverFactory],
    ['updateMany', this.updateManyResolverFactory],
    ['updateOne', this.updateOneResolverFactory],
  ]);

  async create(authContext, objectMetadataMaps, methods): Promise<IResolvers> {
    const resolvers = { Query: {}, Mutation: {} };

    for (const objectMetadata of Object.values(objectMetadataMaps.byId)) {
      // Generate Query resolvers
      for (const methodName of methods.queries) {
        const resolverName = getResolverName(objectMetadata, methodName);
        const resolverFactory = this.factories.get(methodName);
        
        resolvers.Query[resolverName] = resolverFactory.create({
          authContext,
          objectMetadataMaps,
          objectMetadataItemWithFieldMaps: objectMetadata,
        });
      }

      // Generate Mutation resolvers
      for (const methodName of methods.mutations) {
        const resolverName = getResolverName(objectMetadata, methodName);
        const resolverFactory = this.factories.get(methodName);
        
        resolvers.Mutation[resolverName] = resolverFactory.create({...});
      }
    }

    return resolvers;
  }
}
```

### 8. Resolver Factory Pattern

Mỗi resolver factory implement interface `WorkspaceResolverBuilderFactoryInterface`:

**File**: `workspace-resolver-builder/factories/find-many-resolver.factory.ts`

```typescript
@Injectable()
export class FindManyResolverFactory implements WorkspaceResolverBuilderFactoryInterface {
  public static methodName = 'findMany';  // Dùng để mapping

  constructor(
    private readonly graphqlQueryRunnerService: GraphqlQueryFindManyResolverService,
  ) {}

  create(context: WorkspaceSchemaBuilderContext): Resolver<FindManyResolverArgs> {
    return async (_source, args, _context, info) => {
      const options: WorkspaceQueryRunnerOptions = {
        authContext: context.authContext,
        info,
        objectMetadataMaps: context.objectMetadataMaps,
        objectMetadataItemWithFieldMaps: context.objectMetadataItemWithFieldMaps,
      };

      return await this.graphqlQueryRunnerService.execute(args, options, 'findMany');
    };
  }
}
```

## Kết luận

Hệ thống GraphQL auto-generation của Twenty CRM hoạt động dựa trên các nguyên tắc:

1. **Metadata-driven**: Tất cả schema được sinh từ Object Metadata
2. **Workspace-scoped**: Mỗi workspace có schema riêng
3. **Cached TypeDefs**: Schema được cache theo metadata version
4. **Dynamic Resolvers**: Resolvers được tạo mới cho mỗi request với auth context
5. **Factory Pattern**: Sử dụng factories để tạo types và resolvers
